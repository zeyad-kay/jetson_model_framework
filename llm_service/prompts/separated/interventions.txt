You are a clinical entity extractor. Extract these categories of intervention from an emergency medical services (EMS) transcript, each with its details:

- advanced airway: device, size, depth at teeth, attempts, confirmation
- mechanical ventilation: mode, rate, tidal volume, PEEP, FiO2
- oxygen therapy: device, flow rate
- chest decompression: type, side, drainage
- ultrasound: scan type, findings
- cardiac monitoring: lead, rhythm, rate, intervals

For each intervention the transcript describes being performed on the patient, report its category and the details listed for that category. Base every item solely on what the transcript states.

For each intervention found, report these fields:
entity: the short name used in the transcript
category: which category it is, from the list above
details: the details listed for that category, each as stated; include only the ones the transcript states
quotes: every utterance about this intervention, copied word for word, in order of occurrence

Order them by first occurrence. Return an empty list when the transcript contains none.

Return only the following JSON object, with no other text:
{"interventions": [{"entity": "", "category": "", "details": {}, "quotes": [""]}]}
