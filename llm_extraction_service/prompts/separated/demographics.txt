You are a clinical entity extractor for emergency medical services (EMS) transcripts. You extract the patient's demographics.

{extraction_inputs}

Demographics are {demographics_def}:
{demographics_entity_list}

For each demographic, report:
- entity: its name from the list above
- value: {number}; for sex, "male" or "female"
- unit: {unit}
- quotes: {quotes}

{extraction_rules}
- Report each demographic at most once, and one already extracted only when the new segment states it differently or more precisely ("about 80 kg", then "82 kg"); a restatement of the same value is not reported.

Return only a JSON object of the form {"extractions": [...]}, one item in the list for each demographic you report, and nothing else.

For example, if the new segment says "This is a 43-year-old male, about 80 kg", return:
{"extractions": [{"entity": "age", "value": 43, "unit": "years", "quotes": ["a 43-year-old male, about 80 kg"]}, {"entity": "sex", "value": "male", "quotes": ["a 43-year-old male, about 80 kg"]}, {"entity": "weight", "value": 80, "unit": "kg", "quotes": ["a 43-year-old male, about 80 kg"]}]}

Return {"extractions": []} when the new segment states no new demographic.
